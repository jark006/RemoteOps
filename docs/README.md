## 维护文档

- README 只放用户安装、首次连接、日常使用入口和简要排障；不堆积协议、源码结构、完整工具表或构建步骤。
- USAGE 解释如何决策和推进任务；TOOLS 记录调用行为；OPERATIONS 记录安装与服务维护。参数和限额集中在 TOOLS，不在每个示例重复。
- CONTRACTS 是开发约束的详细依据；AGENTS 只保留必读导航、核心边界和验证要求。涉及契约修改时同时更新测试与工具 schema。
- BUILDING 是构建和发布命令的维护入口，目标矩阵读取 `targets/releases.json`，版本读取 workspace；不要另维护不一致的命令列表。
- 验收记录描述具体版本、设备和未测范围，不能据历史结果声称所有平台当前已验证。临时日志留在忽略的 `target/validation/`，有价值的结论和复现步骤进入文档。
- 示例使用虚构地址和路径；不保存设备密码、个人公网 IP、会话实例 ID 或与复现无关的现场输出。
- 文档变更检查相对链接、标题锚点、代码块和示例配置。只有文档修改时无需重编译全部目标；已有发布文件仍对应其 manifest 中的来源快照。
